Welcome to the **JFSG Tools** GitHub repository! This project provides a collection of games for students from the [**Jacobus Fruytier scholengemeenschap (JFSG)**](https://jfsg.nl).
---

## Overview

This repository contains the source code for the **JFSG Tools** games platform, offering a variety of utilities to assist JFSG students with their daily tasks. The goal is to provide an open-source, easy-to-use, and collaborative space for the students.
